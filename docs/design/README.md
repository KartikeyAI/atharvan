# Design direction

`atharvan-dashboard-concept.png` records the approved implementation direction for the initial operator shell: restrained, information-dense, monochrome, and based on shadcn primitives.

The concept is a reference rather than product data. The application must continue to render explicit unknown, partial, empty, loading, and failure states until canonical operational projections are connected.

Rendered browser sign-off remains a release gate for the operator shell. It is intentionally not marked complete by the source-only foundation slice.
